# dev-notes

这个文件夹用来存放开发过程中遇到的技术困难，以及记录技术决策的前因后果。

## 当前结构

- [`overview-20260924-0431.md`](overview-20260924-0431.md)：**现行唯一设计文档**。
  按“每个模块负责什么”组织的模块作用综述，并保留了仍然有效的设计原则、重要经验与演进
  方向。
- 其余文件：仍在进行中的专题笔记。

## 文件内容及规范

文件格式一律为 markdown 格式。

### 文件名规范

`[模块名]-[日期]`。其中日期时间格式为 `YYYYMMDD-hhmm`。

### 维护约定

- 已被落地或被取代的实现细节，从笔记中删除；只保留仍然有效的决策、不变量、教训与未完成
  事项（见仓库历史里的“prune landed progress logs, keep in-force decisions”提交）。
- 当某个专题尘埃落定，把它并入综述，而不是让它以过时正文的形式继续留在文件夹里。
